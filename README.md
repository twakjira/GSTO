# GSTO

Project page and browser predictor for the gated state transition operator (GSTO), an interpretable model for the cyclic response, strength loss, and fragility assessment of reinforced concrete columns.

Page: https://twakjira.github.io/GSTO/

The trained operator is provided for evaluation of the method. The processed data format, program partitions, and analysis code will be deposited in a permanent repository with the accepted article.
